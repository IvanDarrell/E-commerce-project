# Ecommerce Sample Project

This automation is built using selenium java / TestNG with the design pattern of Page Object Model. It covers the user's login and customer action within the Ecommcerce site;
Customer can add, edit, and remove items in the cart. The automation checks the total price to check out and many more! It handles exceptions and define it as hard assertions and soft assertions.


## 🚀 Features
- Navigate pages
- Login
- Add,Edit,Remove items
- Extent Report
   

## 📦 Installation
- Download the file
- Run the testNG.xml in the automation project

## 📓Notes
- When running the automation it's expected to fail as the variables and connection in Database class is updated for GitHub Action (kindly use other database)
- Aside in using other database you can just use the Json file reader to be use in Users Information and the URL used in NAVIGATE method
